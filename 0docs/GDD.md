## 一、游戏概述

### 基础信息
- **游戏类型**：像素风俯视角动作 RPG（类 MMO 战斗 + 房间探索 + 生产养成）
- **开发引擎**：Godot 4.x
- **美术风格**：像素风，TileMap 拼接地图
- **移动方式**：全方向自由移动（非网格锁定）
- **操作方式**：WASD 移动 + 鼠标指向攻击/交互
- **游戏定位**：单机原型，架构预留网游扩展空间

### 核心卖点
- 四本源法则能量体系，战斗 + 生产双维度成长
- 房间探索 + 据点建设的循环玩法
- 悟性差异化技能池，角色build多样性
- 势力与房间能量生态的动态设定

---

## 二、核心玩法循环

```
探索新房间 → 击杀怪物/采集资源 → 获取对应属性能量与材料
	 ↑                                            ↓
解锁更强区域 ← 修炼升级/解锁技能/打造装备 ← 强化自身建设房间
```

### 短循环（分钟级）
进房间打怪 → 掉落能量结晶 + 锻造材料
↓
拾取后安全时使用结晶 → 提升赤焰修为
↓
升级解锁新战斗/生产技能 → 打更强的怪

### 长循环（小时级）
给初始房间充赤焰能量 → 解锁锻造台功能
↓
用刷怪掉的材料锻造装备 → 战力提升
↓
探索更远的赤焰房间 → 获取更好的材料和更多能量

## 三、世界观设定

### 3.1 世界结构
世界由无数大小不一的独立房间（位面裂隙）构成，通过传送门/通道连接。

| 房间类型     | 说明                                             |
| ------------ | ------------------------------------------------ |
| 小型间隙房间 | 无主之地，能量稀薄，偶尔有怪物游荡               |
| 中型房间     | 有稳定生态，怪物聚集，对应主属性能量浓郁         |
| 大型据点房间 | 人类势力掌控，人口聚集，功能完善，有远距离传送阵 |
| 魔兽栖息地   | 高浓度怪物巢穴，高风险高收益                     |

- 相邻房间可通过传送门自由出入
- 大型据点间有势力共建的远距离传送法阵
- 玩家初始位于各大势力之间的无主小型间隙房间

### 3.2 四本源能量体系
世界由四种本源法则构成，每种能量同时覆盖战斗与生产双领域。

#### 赤焰法则（红色）—— 毁灭与重塑
- **战斗方向**：爆发伤害、灼烧 DOT、范围爆炸、破甲
- **生产方向**：炼器锻造、矿石熔炼、装备强化
- **房间功能**：锻造台、熔炉、强化台

#### 生息法则（绿色）—— 生命与生长
- **战斗方向**：治疗、护盾、持续回复、召唤/植物攻击
- **生产方向**：炼丹制药、能量植物种植
- **房间功能**：药圃、炼丹炉、生命回复阵

#### 霜玄法则（蓝色）—— 秩序与构装
- **战斗方向**：冰冻减速、控制、奥术范围伤害、法术护盾
- **生产方向**：附魔铭文、阵法刻录、构装造物
- **房间功能**：附魔台、法阵台、传送阵稳定器

#### 幽影法则（紫色）—— 虚空与衍化
- **战斗方向**：穿透暴击、暗影伤害、潜行减益、腐蚀
- **生产方向**：分解萃取、稀有合成、空间存储、暗影交易
- **房间功能**：分解台、虚空仓库、神秘商人

#### 能量生态规则
- 生物聚集会滋生对应主属性的能量
- 房间主属性由房间内占比最高的生物属性决定
- 人类可通过调整自身能量比例切换主属性
- 怪物/魔兽主属性天生固定，不可切换

### 3.3 势力设定
四大势力各有专长，因资源与能量生态形成竞争格局。

| 势力     | 主属性 | 核心优势                         |
| -------- | ------ | -------------------------------- |
| 烈焰宗   | 赤焰   | 锻造技术最强，武器装备品质最高   |
| 百草堂   | 生息   | 炼丹制药独步天下，治疗体系完善   |
| 霜蓝学院 | 霜玄   | 附魔与阵法研究最深，控场法术最强 |
| 暗影议会 | 幽影   | 掌握稀有合成配方与黑市交易网络   |

#### 势力生态逻辑
- 人口聚集 → 滋生对应主属性能量 → 吸引更多同属性人口 → 正循环
- 各势力以主属性人口为主，但也有其他属性人才
- 普通人无属性信仰，按需切换属性，区位优势主导人口流动
- 势力间因资源与领地常有摩擦与战争

## 四、核心系统

### 4.1 战斗系统

- **战斗模式**：类 MMO 鼠标指向战斗，普攻 + 技能释放
- **伤害体系**：基础伤害 × 属性加成 × 防御减伤 × 暴击/闪避
- **状态效果**：灼烧、冰冻、减速、中毒、护盾等 Buff/Debuff
- **命中判定**：Area2D 碰撞 + 方向角度判定
- **战斗分类**：近战普攻、远程技能、范围AOE、持续DOT

### 4.2 修炼与能量系统
- **四属性独立修炼等级**：每种属性有独立境界/等级，能量为升级经验
- **能量获取途径**：击杀怪物吸收、房间环境缓慢吸收、特殊结晶道具
- **修炼加速方式**：待补充（高浓度房间、丹药、心法、打坐等）
- **主属性切换**：调整自身四属性能量比例即可切换，有冷却/过渡时间
- **等级收益**：提升对应属性伤害/抗性、解锁更高阶技能池、增加技能槽位

### 4.3 技能与悟性系统
- **技能分类**：战斗技能、生产技能两大类
- **大道技能池**：每种属性按修炼等级分层解锁技能池（初/中/高/终极）
- **悟性机制**：
  - 每个角色天生有属性偏向与特质
  - 天生可领悟的技能为总技能池的子集
  - 不同角色技能池有交集也有差异
- **技能传授**：
  - 可通过NPC/能量印记学习后天技能
  - 传授需达到对应属性最低等级，消耗能量
- **技能槽位**：可同时携带的主动技能数量有限，需搭配选择

> 具体技能列表、特质列表待补充

### 4.4 房间与传送系统
- **房间属性**：每个房间有四属性能量浓度、主属性、等级
- **房间等级功能**：按能量浓度解锁对应功能（传送、回复、生产、NPC入驻）
- **传送方式**：
  - 相邻房间传送门（近距离）
  - 大型据点传送法阵（远距离，需解锁）
- **房间建设**：玩家可充能房间、解锁功能、逐步建设自己的据点
- **探索机制**：未探索房间需打破传送门封印进入

### 4.5 生产制造系统
四大生产体系对应四属性能量，与战斗体系并行成长。
- **锻造系统（赤焰）**：武器、护甲打造与强化
- **炼丹系统（生息）**：药品、增益药剂炼制
- **附魔系统（霜玄）**：装备附魔、阵法布置
- **分解合成（幽影）**：装备分解萃取、稀有材料合成
- 生产需在对应功能的房间内进行，消耗材料与对应属性能量

### 4.6 敌人与AI系统
- **怪物属性**：每种怪物有固定主属性，不可切换
- **AI 行为**：巡逻 → 警戒 → 追击攻击
- **怪物分级**：普通怪、精英怪、Boss
- **掉落**：对应属性能量、材料、装备
- **刷新机制**：房间按时间/条件刷新怪物

### 4.7 UI系统（类 MMO 布局）
> 具体UI细节待补充，暂定框架：
- **底部**：技能栏、快捷物品栏
- **左下角**：玩家血条、四属性能量条、修炼等级
- **左上角**：角色状态、Buff/Debuff图标
- **右上角**：小地图、房间信息（主属性、能量浓度）
- **右下角**：菜单按钮（角色、背包、技能、房间管理、设置）
- 浮动伤害数字、交互提示
